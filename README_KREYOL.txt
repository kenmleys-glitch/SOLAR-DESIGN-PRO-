SOLAR DESIGN PRO — EDISYON 3.0
Sous aplikasyon an ak workflow GitHub Actions pou konstwi APK Android.

Kijan pou konstwi APK:
1. Kreye/ouvri repo GitHub SOLAR-DESIGN-PRO.
2. Mete tout fichye ki nan ZIP sa a nan rasin repo a, enkli .github.
3. Commit/push sou branch main.
4. Ale Actions > Android APK Build > Run workflow.
5. Lè workflow la fini, telechaje artifact solar-design-pro-debug-apk.
6. APK la poko siyen pou distribisyon Play Store; se debug APK pou tès.

Fonksyon:
- Antre aparèy, Wh/jou, Watt, èdtan, pik demaraj
- Kalkil konsomasyon, bank batri, PV Wp, kantite pano, inverter
- Verifikasyon string seri/paralèl kont limit MPPT ki antre
- Estimasyon seksyon kab dapre chòk vòltaj (pa ampacity)
- Rapò ak fòmil, avètisman, enprime PDF

Limit sekirite:
- Pwoteksyon/fusible/disjoncteur pa bay valè final otomatik.
- Seksyon kab la se minimòm chòk vòltaj, li pa verifye ampacity, derating, kout-sikwi.
- Verifye done sou fich teknik epi fè pwofesyonèl kalifye apwouve plan an.
